# Коефіцієнти Aqua MODIS → S‑NPP VIIRS для календаря

[frp_modis_viirs_coefficients.csv](../frp_modis_viirs_coefficients.csv) — готова таблиця множників для регіональних UTC-добових сум FRP усіх зареєстрованих детекцій рослинності FIRMS (`type == 0`). Область застосування задають регіони E9 та їхні межі в [regional_daily_inputs.py](../experiments/regional_daily_inputs.py), включно з правилом прикордонної колонки Серрадо. Перевірки використовують лише дні, коли обидва сенсори зареєстрували детекції у відповідній фазі.

Ключ таблиці — `region,phase`. Для окремого D або N використовуйте відповідний рядок. Для повної доби, коли календар має обидві фазові колонки, підсумуйте наявні добутки `k_D × Aqua_D + k_N × Aqua_N`, якщо обидва фазові рядки мають статус `validated_*`. В інших випадках використовуйте рядок `all` і добову суму Aqua. Якщо календар зберігає лише добову суму, застосовуйте `all` одразу. Наприклад, у Серрадо 1000 МВт D і 100 МВт N дають ≈1561,5 МВт. Одна нерозділена сума 1100 МВт дає ≈1565,5 МВт за окремо оціненим множником `all`. Коли Aqua не має записів за добу, значення лишається відсутнім. Для невідомого регіону використовуйте `_default,all` з `k=1`.

`validated_e9` позначає опубліковані оцінки E9 з підтвердженим зниженням MAE. `validated_e10` зарезервовано для моделі, яка проходить обидва часові контролі. `fallback` залишає значення Aqua у вихідній шкалі. Діапазони `fit_*_year` і `control_*_year` фіксують періоди оцінки та перевірки коефіцієнтів. Опубліковані значення Серрадо є відношеннями сум FRP за навчальні дати, тобто середніми добовими відношеннями, зваженими за FRP Aqua. Під час контролю в Серрадо коефіцієнти D/N дали MAE 2664 МВт проти 3060 МВт у сирого Aqua; коефіцієнт `all` для нерозділеної суми дав 2705 МВт.

## E10 · оцінка коефіцієнтів за добовою похибкою

```powershell
.\.venv\Scripts\python.exe -m experiments.e10_calendar_daily_calibration
```

Запуск читає `data/outputs/e9/reported_observations.parquet`, а також західний Parquet і маніфест за 2021–2025 роки. Файл для календаря записується в корінь репозиторію, показники і дослідницькі коефіцієнти — у `data/outputs/e10/`. Модель вибирається на 2015–2016 після оцінки на 2012–2014. Всі варіанти переоцінено на 2012–2016 і перевірено на 2017–2020. Для заходу США додано незалежний контроль 2021–2025 з тими самими коефіцієнтами. Це єдиний регіон, для якого є окремий новий контроль.

Порівняно `k=1`, відношення сум для `all` і D/N, мінімізацію MAE окремо для `all` і D/N та спільне налаштування D/N на добову MAE. Для одного множника мінімум MAE дає зважена медіана відношень S‑NPP/Aqua. Для спільної моделі перевірено 33 заздалегідь задані співвідношення `k_N/k_D` від 0,5 до 2, з точною оцінкою масштабу в кожній точці. На заході США, у південній Амазонії та Серрадо мінімум на навчанні опинився на верхній межі. Розширення діапазону варто перевіряти на нових даних. 95% ДІ різниці MAE отримано парним бутстрепом UTC-тижнів.

| Регіон | 2017–2020, ΔMAE моделі зі спільним D/N, МВт [95% ДІ] | 2021–2025, ΔMAE, МВт [95% ДІ] |
|---|---:|---:|
| Захід США | +79 [−140, +319] | −109 [−210, −17] |
| Схід США | −21 [−31, −12] | — |
| Південна Амазонія | −143 [−287, −13] | — |
| Серрадо | −497 [−675, −339] | — |

Для заходу модель не пройшла обидва часові контролі та окрему перевірку D/N. Для трьох інших регіонів E10 використовував той самий контроль, що й E9. Тому нові коефіцієнти лишаються в `candidate_coefficients.csv`, а у файлі календаря діють підтверджені коефіцієнти E9 або `k=1`. Західний аудит окремо фіксує зміну рядка `source_version` Aqua у 2023 році. Причину відмінностей між часовими періодами цей експеримент не встановлює.

Для наступної перевірки потрібні нові роки для сходу США, Амазонії та Серрадо. Щоб розібрати причини непарних детекцій, можна окремо зіставити вибірку випадків із масками якості [MYD14](https://www.earthdata.nasa.gov/s3fs-public/2023-09/MODIS_C6_C6.1_Fire_User_Guide_1.0.pdf) і [VNP14IMG](https://www.earthdata.nasa.gov/s3fs-public/2024-07/VIIRS_C2_AF-375m_User_Guide_1.0.pdf).
